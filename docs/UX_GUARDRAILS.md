# UX Guardrails

## Never

-   Redesign workflows.
-   Rename business terminology.
-   Change permissions.
-   Change business logic.
-   Introduce new navigation.
-   Add unnecessary filters.
-   Duplicate actions.
-   Remove existing functionality.

## Always

-   Preserve user workflow.
-   Improve consistency.
-   Prefer existing UI patterns.
-   Keep modules visually aligned.

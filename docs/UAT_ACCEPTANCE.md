# UX UAT Acceptance Criteria

A change is complete only if all checks pass.

## Layout

-   Shared page rhythm followed where applicable.
-   Toolbar aligned.
-   No unnecessary wrapping.

## Components

-   Buttons consistent.
-   Filters consistent.
-   Tables consistent.
-   Modals consistent.

## Behavior

-   Role permissions unchanged.
-   Exports work.
-   Row click works.
-   Keyboard navigation unaffected.

## Visual QA

-   Spacing consistent.
-   Alignment consistent.
-   Desktop layout verified.
-   No regressions introduced.

# Table Guideline

## Goal

Optimize readability while preserving operational efficiency.

## Column Priority

1.  Operational fields
2.  Context fields
3.  Audit fields
4.  Detail-only fields

## Rules

-   Keep only decision-making information visible.
-   Move historical metadata into detail pages.
-   Avoid horizontal scrolling where practical.
-   Row click opens detail.
-   Inline actions should be minimal.
-   Support sorting, filtering, export, and pagination consistently.
